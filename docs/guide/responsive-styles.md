# 響應式樣式

Sigil 的 Desktop 樣式沿用既有 `style`；Tablet 與 Mobile 只保存差異覆寫。這是 additive 的 schema v1 欄位，舊文件不需要 migration。

```ts
const node = {
  id: 'hero',
  type: 'section',
  style: {
    padding: '48px',
    'font-size': '32px',
  },
  responsiveStyles: {
    tablet: {
      padding: '32px',
    },
    mobile: {
      padding: '16px',
      'font-size': '24px',
    },
  },
}
```

## 繼承規則

- Desktop 只使用 `style`。
- Tablet 使用 `style`，再套用 `responsiveStyles.tablet`。
- Mobile 使用 `style`，再依序套用 Tablet、Mobile 覆寫。
- 在非 Desktop 裝置按「使用繼承」，會刪除該 property 的覆寫，而不是複製上一層的值。
- 清除某個 breakpoint 只影響該層；Desktop 與其他 breakpoint 保留。

`createApp()` 與 `createEditor()` 的裝置按鈕會同步 Canvas 和樣式面板。面板會標示每個值是目前裝置的「覆寫」，還是繼承自 Desktop／Tablet。

## 分別調整四邊間距

要替手機版「活動資訊」卡片的底部多留空間，先選取卡片、切到「手機」，在「樣式 → 版面」展開「分別調整內距」。在「下方內距」輸入 `32px` 並按 Enter。其餘三邊繼續沿用原來的設定。要改卡片與相鄰元件的距離，可用「分別調整外距」。外距也可輸入 `auto` 或負值。

欄位會顯示目前裝置採用的值，包括從 `padding: 8px 16px` 這類簡寫取得的各邊。按某一邊旁的還原按鈕，只會移除該裝置的單邊設定，隨即顯示同裝置簡寫或較寬裝置提供的值。若四邊都要換成同一組設定，可直接改內距或外距的簡寫，或選擇內距預設。

若匯入的間距由 CSS 變數簡寫或書寫方向決定，欄位會顯示「依 CSS 宣告決定」。仍可覆寫其中一邊；清除該覆寫後，原本的 CSS 會重新生效。

## 調整文字排版

選取畫布上的活動標題，按元件工具列的「調整文字排版」。焦點會移到「樣式 → 文字 → 文字排版預設」。選擇一組預設可一次調整四個屬性，隨即在畫布看到結果。一次復原可還原這次套用。

| 預設     | 字級                     | 行高   | 字重  | 字距       |
| -------- | ------------------------ | ------ | ----- | ---------- |
| 展示標題 | `clamp(2rem, 5vw, 4rem)` | `1.1`  | `700` | `-0.035em` |
| 章節標題 | `2rem`                   | `1.25` | `600` | `-0.015em` |
| 內文     | `1rem`                   | `1.6`  | `400` | `normal`   |
| 註解     | `0.875rem`               | `1.4`  | `400` | `0.02em`   |

例如，桌面主標題可用「展示標題」，切到「手機」後改用「章節標題」。兩種裝置仍共用同一個 H1。要單獨增加行距，可在「行高」輸入 `1.45` 並按 Enter。若只想把手機的字距改回上一層，在「字距」旁按「使用繼承」。預設只在目前裝置寫入有差異的值。

## 使用頁面上的顏色

要讓活動標題沿用按鈕的藍色，選取標題，開啟「樣式 → 文字」，在「文字顏色」旁按「頁面色票」，再選 `#243e83`。色票依頁面順序列出目前裝置上元件使用的文字色與背景色。點一次即可套用，按一次「復原」即可還原。

要讓手機的活動資訊區使用半透明底色，先切到「手機」，選取「活動資訊」，開啟「樣式 → 外觀」。在「背景顏色」貼上 `rgba(52, 128, 92, 0.5)` 並按 Enter，或點左側色塊使用系統選色器。欄位也會顯示原本由 `background` 簡寫設定的底色。按「使用繼承」可移除手機的顏色覆寫。

如果輸入的色值有誤，欄位會保留輸入供修正，按 Escape 可回到原值。Laravel 範例可儲存十六進位色碼、`rgb()`、`hsl()` 與具名色，輸入 CSS 變數時會直接提示宿主的儲存限制。

## 在元件之間複製樣式

選取已排版的元件，在樣式面板按「複製樣式」。接著選取目標元件與要修改的裝置，按「套用樣式」。你可以從桌面標題複製字級與行高，再切到手機套用到另一個標題。面板會顯示來源元件和複製時的裝置。

複製範圍是文件為該元件設定的樣式，包含當前裝置從較寬裝置取得的值。套用只寫入目標裝置上有差異的屬性，相同值繼續沿用原本的繼承關係。目標獨有的樣式、文字、連結與 CSS class 都會保留。一次復原即可還原整次套用。樣式暫存在這個編輯器中，可連續套用至多個元件。

## 在面板調整手機排列

1. 選取區段，切到「手機」，再開啟右側「樣式」的「版面」。
2. 在「顯示方式」選「彈性排列」，從「排列方向」選「直向」，再調整「項目對齊」與「項目間距」。選「自訂 CSS 值」可沿用宿主自己的尺寸或 CSS 表達式。
3. 切回「桌面」檢查原有排列，或在手機樣式按「使用繼承」還原其中一個欄位。下載的 HTML 會依閱讀者的視窗寬度套用相應樣式。

「版面」「文字」「外觀」可獨立收合。切換元件或裝置時，面板會記住展開的分類。

### 讓同一排按鈕在手機換行

1. 選取裝有按鈕的容器，將「顯示方式」設為「彈性排列」，「排列方向」設為「橫向」。桌面使用「不換行」。
2. 切到「手機」，把「項目換行」改為「自動換行」。放不下的按鈕會移到下一列。若要讓新的一列出現在前一列的另一側，可選「反向換行」。
3. 展開「分別調整間距」，在「列間距」輸入 `12px`，按 Enter，再在「欄間距」輸入 `20px`。這組橫向按鈕的上下兩列相隔 12px，同列按鈕之間相隔 20px。格線容器也可分別編輯這兩項間距。

每次修改都可復原。要恢復原本的換行，按「還原換行設定」。列間距與欄間距各有清除覆寫的按鈕，清除後會回到目前簡寫或較寬裝置的值。匯入的 `flex-flow` 與 `grid-gap` 可繼續使用，調整換行會保留原排列方向。

## 依裝置調整格線欄數

選取包含卡片的區段，開啟「樣式」的「版面」。在桌面按「3 欄」，再切換到平板按「2 欄」、手機按「1 欄」。子元件會依原有順序換列，每次調整都可單步復原。「項目間距」可另外調整卡片間的距離。

若兩欄需要不同寬度，可在「自訂欄寬」輸入 `minmax(0, 2fr) minmax(0, 1fr)`，按 Enter 後，第一欄便會佔用兩倍的可分配空間。在平板或手機按「沿用上層欄寬」，即可讓欄寬跟隨較寬裝置。下載的 HTML 會依讀者的視窗寬度套用設定。

Laravel 範例支援上面的比例、固定尺寸與 `repeat(auto-fit, …)` 等寫法。若輸入 CSS 變數或具名格線，面板會提示該網站的欄寬限制，並保留原有配置。

## 讓標題橫跨整列

在三欄的「活動資訊」區段中，從畫布或圖層選取子元件「資訊標題」，開啟「樣式 → 版面」，按「橫跨整列」。標題會獨佔第一列，時間、地點與參加對象依文件順序排在下一列。這項操作也適用於格線裡的圖片、按鈕或卡片。

若平板上的標題要和時間並排，切到平板並按「自動排列」。手機預設沿用平板配置，也可單獨調整。按「沿用上層配置」可清除本裝置的跨欄設定。若本裝置已透過 CSS `grid-area` 指定區域，調整跨欄時會保留列位置。在平板或手機按「還原區域配置」可回到原先指定的欄位。

## 調整活動主圖的構圖

1. 在畫布選取活動圖片，從圖片工具列按「調整圖片構圖」。也可從右側「內容」的同名按鈕進入，或直接開啟「樣式」。
2. 選擇「桌面」「平板」或「手機」，再設定「裁切比例」。例如桌面用 16:9 呈現橫幅，手機改用 1:1，替活動主角保留更多畫面。
3. 在「圖片適應方式」選「填滿裁切」，點選或拖曳到原圖中想保留的位置，再從畫布檢視裁切效果。若需完整呈現整張圖片，可選「完整顯示」。

要精確定位，可輸入水平及垂直焦點百分比。原圖左上是 0%、0%，中心是 50%、50%。使用鍵盤時，按 Tab 移到原圖，使用方向鍵每次移動 1%，按住 Shift 可一次移動 10%。

套用比例時，編輯器會將目前裝置的圖片高度設為自動，並解除原有的高度上下限，讓畫布呈現選定的比例。圖片原先未指定適應方式時，會一併使用填滿裁切。按一次復原即可還原這些變更。

在手機或平板按「沿用上層焦點」，即可恢復較寬裝置的焦點。比例、高度、上下限與適應方式也可另外恢復繼承。儲存後下載的 HTML 會依讀者的螢幕寬度套用構圖。

## Core API

```ts
import { createStylePatch, getEffectiveStyle, getStyleSource } from '@cluion/sigil-core'

const effective = getEffectiveStyle(node, 'mobile')
const source = getStyleSource(node, 'mobile', 'padding')

engine.update(node.id, createStylePatch('tablet', 'padding', '24px'))
engine.update(node.id, createStylePatch('tablet', 'padding', '')) // 回到繼承
```

預設 breakpoint 為 Tablet `max-width: 768px`、Mobile `max-width: 480px`。目前不提供自訂 breakpoint 編輯器。

## HTML 輸出

`toHTML()` 只在文件包含 responsive 覆寫時加入一段 `<style data-sigil-responsive>`，並用穩定的 `data-sigil-r` 標記把 media query 對到節點。Tablet 規則先輸出、Mobile 後輸出，因此 Mobile 自動繼承 Tablet。

有斷點覆寫的節點會把 Desktop 基底也放在同一份樣式表，讓窄螢幕的覆寫優先。標記由各斷點的樣式內容產生，可在同一個頁面嵌入多份片段。

「下載 .html」會產生含 UTF-8 與 viewport 宣告的獨立頁面。宿主可透過 `createApp({ getExportTitle: (doc) => ... })` 指定下載頁面的標題，預設取用 `doc.meta.title`，其次使用根節點名稱。「複製」與 `toHTML()` 提供可嵌入宿主頁面的 HTML 片段。

Static 與 hydrated shortcode 都保留相同的樣式行為。Static shortcode 若有 class、attribute、base style 或 responsive style，輸出會建立一層 `<div>` host 來承載 presentation；沒有 presentation 的 shortcode 維持原本的純 static HTML。
